# Homey — Home Building Made Easy

A demo of Homey: a lot-buildability screening service for Southeastern
Massachusetts. Buyers get a **Lot Check** ($149, 48-hour turnaround) that
screens a parcel against wetlands, nitrogen-sensitive/septic triggers, flood
zone, soil drainage, zoning/setbacks, priority habitat, and wellhead
protection. Builders get a flat-rate **membership** to route unqualified
inquiries to Homey instead of burning estimator hours on them.

This is a front-end demo — there's no backend, payment processing, or real
GIS integration. The Lot Check report is generated by a deterministic mock
engine (`src/lib/lotCheck.ts`) that hashes the address + town into a seeded
PRNG, so the same input always produces the same report, and different
addresses produce genuinely different findings.

## Pages

- `/` — landing page, problem framing, both audiences
- `/lot-check` — address/town intake form with a simulated GIS-scan animation
- `/report` — the generated screening report (risk categories, verdict, cost estimate)
- `/builders` — membership pricing, founding rate, an interactive ROI calculator
- `/how-it-works` — data sources, the automation + human-review pipeline, disclaimers

## Stack

Vite + React + TypeScript + Tailwind CSS v4 + React Router.

## Running locally

```bash
npm install
npm run dev
```

Build for production with `npm run build`.
